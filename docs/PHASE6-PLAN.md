# План разработки: Фаза 6

Этот документ содержит детальный план шестой фазы разработки aprover — **Расширение системы аксиом и улучшение ядра прувера**.

## Обзор Фазы 6

Фаза 6 направлена на расширение возможностей прувера путём добавления новых производных правил, улучшения алгоритмов унификации и создания инструментов для работы с более сложными доказательствами.

### Цель фазы

Расширить ядро прувера для поддержки:
- Производных правил вывода на основе существующих аксиом
- Улучшенной обработки рекурсивных форм
- Кэширования результатов доказательств
- Метрик и статистики доказательств
- Батчевой обработки выражений

---

## Анализ текущего состояния

### Текущие возможности прувера (v0.8.0)

| Компонент | Статус | Описание |
|-----------|--------|----------|
| Унификация | ✅ Реализовано | Структурная унификация с подстановками |
| Modus Ponens | ✅ Реализовано | Автоматическое применение MP |
| Транзитивность | ✅ Реализовано | A1: {(x = y), (y = z)} → (x = z) |
| Конгруэнция | ✅ Реализовано | A2: {(a = c), (b = d)} → ((a → b) = (c → d)) |
| Рекурсивное свёртывание | ✅ Реализовано | A4, A5, A6 |
| Интерактивный режим | ✅ Реализовано | Пошаговое доказательство |
| Экспорт доказательств | ✅ Реализовано | LaTeX, Text, JSON, DOT |

### Выявленные возможности для улучшения

1. **Кэширование доказательств**
   - Результаты verify() не кэшируются между вызовами
   - Повторные проверки одинаковых выражений выполняются заново

2. **Метрики доказательств**
   - Нет сбора статистики о процессе доказательства
   - Невозможно измерить сложность доказательств

3. **Производные правила**
   - Нет поддержки пользовательских правил вывода
   - Нельзя определять леммы для повторного использования

4. **Батчевая обработка**
   - Нет оптимизации для проверки множества выражений
   - Каждое выражение проверяется независимо

5. **Отладка доказательств**
   - Трассировка ограничена
   - Сложно понять причины неудачи доказательства
